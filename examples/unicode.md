# Unicode display check

Use normal text mode to check your terminal's fonts and character widths.
Typeset mode currently embeds Latin fonts and does not cover emoji, CJK, or
block-drawing characters. Press `s` to compare rendered Markdown with source.

Emoji: 🙂 🚀 👩🏽‍💻 👨‍👩‍👧‍👦 🇯🇵 ❤️ 1️⃣

Shortcodes: :heart: :fire: :+1: :rocket:

Literal code: `:heart: :fire:`. Escaped: \:heart:. Unknown: :gloss_unknown:.

Accents: café naïve é ä

Halfwidth and fullwidth: ｶﾀｶﾅ カタカナ ＡＢＣ ABC

```text
Blocks: ▀▄▌▐ █░▒▓
Box:    ┌────┬────┐
        │ A  │ B  │
        └────┴────┘
```

Try searching for `👩🏽‍💻` or `▀▄▌▐`, then resize the window.
