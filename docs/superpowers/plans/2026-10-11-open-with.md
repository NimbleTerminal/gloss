# Open with Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementation was authorized and completed inline on `feat/open-with`; manual platform checks below remain outstanding.

**Goal:** Open the current or highlighted local file in a native app, with a chooser and saved defaults per format.

**Architecture:** A native host owns trusted app discovery, bounded preferences and process launch. The pager receives a narrow interface and implements one chooser over document, menu, grid and browser screens. The independent browser emits an intent message; it never launches a process.

**Tech Stack:** Go, Bubble Tea v2, existing lipgloss/picture overlays, os/exec, encoding/json, browsetest; no new module dependency.

**Spec:** [Open with design](../specs/2026-10-11-open-with-design.md). Read it before executing any task.

## Global constraints

- Phase 1 only: pager, catalog, preferences, `--apps [--json]`, docs and tests.
- Go package prefix `nimbleterminal.dev/gloss`; project `github.com/NimbleTerminal/gloss`.
- Existing Go minimum 1.26.9; use `GOTOOLCHAIN=go1.26.9 GOWORK=off` for the commands below if the installed newer compiler is incompatible with the pinned analysis tools.
- `w` default, `W` chooser, browser Alt+Enter, chooser `d` saves without launching.
- Preference input maximum 64 KiB; only trusted catalog IDs, no command strings.
- No shell, terminal editors, server endpoints, automatic downloads or changes to temporary-file lifetime.
- `Options.OpenWith` is nil for served viewers, public browser hosts and previews.
- Root CI and demo/WASM validation must pass before calling Phase 1 complete.
- Preserve unrelated work. Do not alter `../go-thinkt`; retain MIT attribution for copied code.

## Review focus

1. A late chooser result must not open or relabel a different highlighted file (Task 4).
2. Browser letters must remain filter text, while an active chooser owns its letters (Tasks 3–4).
3. Spaces, quotes, commas, leading dashes and terminal escapes in filenames must not alter argv or UI (Tasks 1, 4).
4. A missing saved app or failed preference write must not silently change the saved selection (Task 2).
5. WASM or served-session input must never gain native launch capability through shared code (Tasks 4–5).

## File map and interfaces

New `internal/openwith/types.go` holds portable Target, Choice and Host from the spec.
`catalog.go` owns native Entry, Probes, Catalog and supported-kind matching.
`catalog_darwin.go`, `catalog_linux.go`, `catalog_windows.go`, and
`catalog_other.go` own platform commands/probes. `launch.go` owns argv and process
lifetime. `preferences.go` owns JSON validation and atomic replacement;
`host.go` combines them. All except types.go and portable tests use `!js` tags.
Tests live beside each file. App integration is in `internal/app/open_with.go`
and `open_with_test.go`; native target acquisition is in `open_with_native.go`,
with `open_with_js.go` for unavailable hosts.

The following native signatures are shared across tasks:

```go
type Entry struct { ID, Name string; Kinds, Exec []string }
type Probes struct {
    LookPath func(string) (string, error)
    Stat func(string) (fs.FileInfo, error)
    Home string
}
type Catalog struct {
    Entries []Entry       // full platform catalog, including unavailable apps
    Available map[string]bool
}
func Discover(goos string, probes Probes) (Catalog, error)
func BuildCommand(entry Entry, path string) (string, []string, error)
func Start(entry Entry, path string) error
type Preferences struct {
    Defaults map[string]string `json:"defaults"`
    Hidden []string `json:"hidden"`
}
func ReadPreferences(dir string, catalog Catalog) (Preferences, error)
func WritePreferences(dir string, prefs Preferences) error
func NewHost(catalog Catalog, dir string) (Host, error)
```

Discover takes an explicit OS for table testing; platform files supply executable
resolution/reveal details without requiring another OS in CI. Keep stat/LookPath
injected. NewHost returns a usable default host plus a nonfatal error for malformed
preferences; fatal errors return nil. Native tests use an internal starter seam:

```go
type child interface { Start() error; Wait() error }
type starter func(string, ...string) child
func startWith(newChild starter, entry Entry, path string) error
```

Use a concrete exec.Cmd adapter since Go does not covary function return types.
The host guards preferences with a mutex and never holds it while launching.
Host.Launch validates the target again; Host.SetDefault validates against catalog
compatibility and availability. Host.Choices is side-effect-free. “system” and
“reveal” are reserved IDs; “copy” is app-local only.

## Plan review and handoff

Coverage checked against the spec: all Phase 1 contexts, kind resolution, default
fallback, catalog restrictions, persistence, process lifecycle, listing/schema,
WASM/server boundaries, docs and tests have owning tasks above. Phase 2 endpoint
tests and terminal editors are deliberately excluded from execution. No feature
has been implemented or tested merely by writing this plan.

Recommended execution is native in the current session: the five tasks share a
small host interface and one event loop, so keeping their integration context is
useful. Review the spec and plan before authorizing implementation. Do not spawn
workers without explicit authorization in the executing session.

## Execution result

Implemented inline in `/private/tmp/gloss-open-with`. Tests exercised missing
implementations first, then argv/reaping, bounded preferences, browser intent,
chooser routing, duplicate submit, canceled/stale replies, save errors, temporary
provenance, host isolation, narrow layouts and JSON schema. Full `task ci demo-check` (with GOTOOLCHAIN=go1.26.9 and GOWORK=off) and `task build-wasm-site`
passed. A built-binary `--apps --json` smoke check returned 14 format groups.
No GUI applications were launched during automated verification.

Implementation rulings: native platform policy is one injected-platform catalog
file; the picker uses an opaque modal body, with the old view retained; the
initial catalog is limited to macOS Preview/Skim and four existing thinkt GUI
editor launch patterns, plus system/reveal. Omitted slicer/office/image-tool
entries need invocation verification before adding them. Review found hidden
small-window actions and a wrapping footer; both were reproduced and fixed.
Docs and implementation are committed separately. The original checkout's
experimental dependency changes and README.txt were not touched.
